# AI Policy

Using AI (LLMs) as tools for development is allowed. However, all contributions to this project are held to a high standard of quality, and contributors are expected to be responsible for any code or issues they submit.

AI may not be used to generate responses to questions in PRs, issues, or other communications with project participants or maintainers.

This project requires a human in the loop who understands and can explain all changes made.

If you use AI to translate, include the original language text and put the translation in a blockquote.

Failure to follow this policy will result in PRs or issues being closed or hidden; continued violations may result in a ban from the project.

AI is a useful tool for development, but improper use results in an unmanageable workload for maintainers. Please respect the time and effort others put into managing this project.
